Cambios sin publicar

¿Cómo publicar los cambios para los pasajeros?
  1. Edita el catálogo aquí. Los cambios se guardan como borrador en este navegador y no los ven los pasajeros.
  2. Revisa el resultado con Vista previa.
  3. Presiona Exportar JSON: se descarga el archivo catalogo.json.
  4. En GitHub, sube ese catalogo.json al repositorio reemplazando el anterior (Add file → Upload files → Commit changes).
  5. En 1 a 2 minutos el portal mostrará el catálogo actualizado a todos los pasajeros.

El borrador solo existe en este navegador: para trabajar desde otro equipo, exporta el JSON y luego impórtalo allá.
